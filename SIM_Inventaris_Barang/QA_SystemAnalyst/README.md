#📌 System Analyst — SIM Inventaris Barang
---
Folder ini berisi seluruh rangkaian analisis sistem untuk proyek SIM Inventaris Barang, yang saya kerjakan dalam konteks magang dan tugas akhir sebagai backend web developer sekalius System Analyst. Sebagai System Analyst, saya bertanggung jawab mengumpulkan kebutuhan pengguna, menganalisis proses kerja, membuat model sistem (Use Case, BPMN, ERD), melakukan validasi dengan stakeholder, serta memberikan pelatihan sistem. Dokumentasi ini digunakan oleh developer sebagai acuan pembuatan sistem dan oleh QA sebagai acuan pengujian.
Dokumen-dokumen ini menggambarkan proses bisnis, arsitektur sistem, alur data, dan validasi fungsional sistem.

## 📂 Daftar Dokumen

+ **1. Requirement Gathering**
+ Pada tahap ini dilakukan wawancara, observasi, dan diskusi dengan instansi (kepala sekolah, humas, team web, dan staff sarpras) untuk mengetahui permasalahan dan kebutuhan dari pengguna.
---
+  **2. Analisis Kebutuhan Fungsional dan Non-Fungsional**
+  Berisi analisi untuk membangun sistem yang lengkap, berkualitas, dan memenuhi harapan pengguna.
+  - Kebutuhan Fungsional, untuk menentukan "apa" yang sistem lakukan (fitur, proses)
   - Kebutuhan Non-Fungsional, untuk menentukan "bagaimana" sistem melakukan (keamanan,     kemudahan pengguna, dan performa sistem)
    Tujuannya adalah memastikan sistem tidak hanya berfungsi sesuai spesifikasi tetapi juga mudah digunakan, aman, cepat, dan stabil, sehingga memberikan pengalaman pengguna yang optimal dan mencapai tujuan bisnis.
---
+  **3. Analisis Proses Bisnis**
+  Menjelaskan alur proses secara visual dari setiap proses dalam sistem lama dan baru:
   - Flowchart proses lama
   - Flowchart proses baru
   Flowchart membantu memberikan gambaran ringkas mengenai urutan proses, kondisi, dan interaksi antar komponen.
---
+  **4. Use Case Diagram**
+  Berisi use case diagram yang dirancang untuk menggambarkan interaksi user dengan sistem. Beserta Use case desription untuk menjelaskan detail tiap langkah.
---
+  **5. Activity Diagram**
   Berisi alur aktivitas sistem yang dilakukan oleh Admin pada berbagai fitur sistem:
   - Activity Diagram login admin
   - Activity Diagram data master kategori (tambah, edit, hapus)
   - Activity Diagram data master barang (tambah, edit, hapus, cetak/unduh label barang)
   - Activity Diagram data master lokasi (tambah, edit, hapus)
   - Activity Diagram barang masuk (tambah, edit, hapus)
   - Activity Diagram barang keluar (tambah, edit, hapus, cetak/unduh label barang)
   - Activity Diagram barang hilang (tambah, edit, hapus)
   - Activity Diagram cetak laporan
   Dokumen ini menggambarkan detail proses mulai dari input data, validasi, hingga keputusan penting dalam sistem.
---
+ **6. ERD (Entity Relationship Diagram)** 
   Menjelaskan struktur tabel database, relasi antar tabel, atribut utama, dan alur penyimpanan data dalam sistem.
---
+ **7. Arsitektur Sistem**
   - Arsitektur Sistem_CareerApp.png  
   Menggambarkan komponen utama sistem, interaksi antar modul, teknologi yang digunakan, serta alur data dari frontend ke backend.
---
+ **8. UAT (User Acceptance Testing)**
   Berisi skenario uji penerimaan pengguna (User Acceptance Test) untuk memastikan fitur berjalan sesuai kebutuhan bisnis. Termasuk test scenario, expected result, actual result, dan status uji.
---
 **9. Estimasi Pengerjaan Aplikasi**
    Berisi penjelasan mengenai detail fitur, timeline estimasi pengerjaan, dan juga alokasi tenaga kerja yang dibutuhkan.
 
## 📎 Catatan
Semua dokumen di dalam folder ini merupakan bagian dari analisis sistem pada proyek **SIM Inventaris Barang** dan dibuat untuk kebutuhan portofolio profesional.
